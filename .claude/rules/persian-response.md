# Language rule (persistent)

- Write **every** user-facing response in Persian (فارسی), right-to-left.
- This is a standing rule, not a one-shot instruction: it applies to all turns until the
  user explicitly asks for a different language.
- It applies regardless of the language the user writes in.
- Keep code, file paths, identifiers, shell commands, log output, and URLs in their
  original form inside the Persian prose.
- Commit messages, code comments, and workflow files may stay in English; the Persian
  requirement covers chat responses to the user.
